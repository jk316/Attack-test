# 数据模型：Ping 监控与 RTT 观测

**特性**: `specs/003-ping-monitor-rtt/` | **阶段**: 1 设计 | **日期**: 2026-11-19

实体与字段以规格「关键实体」为准；JSON 形状细节见 `contracts/`，本文件描述结构、关系、校验规则与状态流转（不含实现细节）。

## 实体

### 1. 监控样本（MonitorSample）

一次探测的结果，或高分辨率模式一个摘要周期的汇总结果。

| 字段 | 类型 | 说明 |
|------|------|------|
| `ts` | 数字（秒，浮点） | 解析该行时的采集时刻（`time.time()` 时钟源，与攻击时刻 t0 同源） |
| `rtt_ms` | 数字 或 null | RTT（毫秒）；探测丢失或摘要周期全丢时为 null |
| `sent` | 整数 ≥ 0 | 发送数：逐探测后端为 1；fping -Q 周期为该周期的探测数 |
| `received` | 整数 ≥ 0 | 收到数：逐探测后端为 0 或 1；fping -Q 周期为该周期的收到数 |

**校验规则**:
- `received ≤ sent`；`received == 0` 时 `rtt_ms` 必须为 null。
- 缓冲有界（默认 4000，可配置）：写满时淘汰最旧样本。
- 样本按解析先后追加，同缓冲内天然时间递增（查询接口不依赖此性质，按 `ts` 过滤）。

### 2. 监控实例（PingMonitor）

全局唯一的后台监控器（进程级单例）。

| 属性 | 类型 | 说明 |
|------|------|------|
| 目标 IP | 字符串 或 null | 当前监控目标；未运行时为 null |
| 运行状态 | 布尔 | 探测子进程是否存活 |
| 后端 | 枚举 | `fping_q`（高分辨率）/ `ping`（系统回退） |
| 样本缓冲 | MonitorSample 集合 | 线程安全、有界 |

**状态流转**:
```
未启动 ──start(ip)──▶ 运行中 ──stop()──▶ 已停止 ──start(ip')──▶ 运行中
                      ▲  │
                      └──┘（运行中再次 start：先停止旧监控再以新目标启动）
```
- `start(ip)` 前置：目标经安全校验（格式合法、非广播/组播、在 allowlist）；校验失败即拒绝且状态不变。
- `stop()` 幂等：进程已退出或线程已结束时安全返回。
- 后端选择在 start 时按运行时探测确定（非 Windows 且 fping 可用 → `fping_q`，否则 `ping`）。

### 3. 攻击窗口（attack_window）

一次攻击动作的时间范围（由观测构造在攻击结束时生成）。

| 字段 | 类型 | 说明 |
|------|------|------|
| `start` / `end` | 时间点（数值 `ts` + 本地时间字符串 `iso`） | 攻击开始（t0）与观测构造时刻 |
| `duration_s` | 数字 | 攻击窗口时长（end − start，秒） |
| `mode` | 字符串 | 执行模式标注（如 `scapy` / `live` / `dry_run`） |

### 4. 观测窗口（observation_window）

攻击窗口对应的样本覆盖诊断。

| 字段 | 类型 | 说明 |
|------|------|------|
| `sample_count` | 整数 ≥ 0 | t0 之后取到的样本数 |
| `first_sample` / `last_sample` | 时间点 或 null | 窗口内首/末样本时刻；无样本为 null |
| `covers_attack_window` | 布尔 | 观测是否真正覆盖攻击窗口（判定规则见 contracts/rtt-observation.md） |
| `note` | 字符串 | 人可读诊断说明（未覆盖原因 / 覆盖概况与丢包提示） |

### 5. 攻击期间观测（rtt_during）

攻击窗口内逐样本 + 聚合统计；无数据时为 null。

| 字段 | 类型 | 说明 |
|------|------|------|
| `samples` | MonitorSample 列表 | t0 之后、时间先后排序的逐样本 |
| `avg_rtt_ms` / `min_rtt_ms` / `max_rtt_ms` | 数字 | 仅统计收到的探测，多探测样本按收到数加权 |
| `loss_pct` | 数字（0–100） | `1 − 收到总数/发送总数` |
| `total_sent` / `total_received` | 整数 | 窗口内收发总数 |

### 6. 单次测量结果

一次有限探测的测量结果（独立于持续监控）。

| 字段 | 类型 | 说明 |
|------|------|------|
| `success` | 布尔 | 是否成功获得测量（全部丢失时可为 true，RTT 为不可用） |
| `avg_rtt_ms` | 数字 或 无穷大 | 平均 RTT；全部丢失为不可用（无穷大），不得为 0 |
| `loss_pct` | 数字（0–100） | 丢失率 |
| `packets_transmitted` / `packets_received` | 整数 | 收发计数 |
| `raw_output` / `error` | 字符串 | 原始输出或失败原因 |

## 关系

- 监控实例 **1─n** 监控样本（有界缓冲）。
- 攻击窗口与观测窗口由同一次观测构造生成，**1─1** 对应；观测窗口引用攻击窗口时间范围做覆盖判定。
- rtt_during 的数据来源是监控实例按 t0 的采样查询；无监控/无样本/全丢失时为 null。
- 单次测量与持续监控相互独立，共用同一目标安全校验。

## 校验规则（跨实体）

- 时间语义：`start.ts ≤ 各样本.ts ≤ end.ts` 是「覆盖」的必要条件（非充分，见契约判定规则）。
- 丢失率口径：统一 `1 − 收到/发送`；发送数为 0 时不产生丢失率（按 0 处理）。
- 诚实性原则（FR-012）：监控未运行、无样本、全丢失、窗口 < 1 s 四类情况，`covers_attack_window` 必须为 false 且 note 写明原因；未覆盖的观测不得作为决策依据。
