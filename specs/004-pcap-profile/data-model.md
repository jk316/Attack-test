# 数据模型：PCAP 业务流量画像

**特性**: `specs/004-pcap-profile/` | **阶段**: 1 设计 | **日期**: 2026-11-19

实体与字段以规格「关键实体」为准；JSON 形状与映射契约细节见 `contracts/pcap-profile.md`，本文件描述结构、关系、校验规则（不含实现细节）。

## 实体

### 1. 业务流量画像（Profile）

一次抓包分析的结构化结果。

| 字段 | 类型 | 说明 |
|------|------|------|
| `top_dst_ips` | 字符串数组（≤10） | 目标 IP 按出现次数降序，前 10 |
| `top_dst_ports` | 整数数组（≤10） | 目标端口按出现次数降序，前 10 |
| `packet_size_hist` | 对象（桶名 → 概率） | 桶：`64/128/256/512/1024/other`；各桶概率之和为 1 |
| `iat_ms_stats` | `{mean, p50, p90}` | IAT 毫秒统计；无 IAT 时全 0 |
| `flow_stats` | `{approx_flow_count, timeout_s}` | 近似流数与所用空闲阈值 |
| `payload_len_stats` | `{mean, p50, p90}` | UDP 负载长度统计；无 UDP 时全 0 |
| `notes` | 字符串（非空） | 口径说明 + 截断/忽略/异常记录 |

### 2. 流（Flow）

以 5 元组 + 空闲超时近似区分的通信序列。

- **键**: `(src_ip, src_port, dst_ip, dst_port, protocol)`（UDP-only 口径下 protocol 恒为 UDP）。
- **断流规则**: 同一键内包按时间排序，相邻包间隔 > `idle_timeout_s`（默认 30，可配置）视为新流；键首次出现即计 1 个流。
- **约束**: 仅 UDP 包参与；src_port 缺失或异常（如 0）时按出现值处理并可在 notes 注明。

### 3. 包到达间隔样本（IAT）

- 分组键: `(dst_ip, dst_port)`。
- 计算: 组内按包时间排序，相邻两包时间差 × 1000 → 毫秒序列；组内包数 < 2 不产生样本。
- 聚合: 均值 / 中位数 / P90（百分位定义见契约）。

### 4. 包长桶

- 边界: `≤64 / ≤128 / ≤256 / ≤512 / ≤1024 / >1024（other）`，按包总长（含头）分桶。
- 归一化: 桶计数 / UDP 包总数；和为 1（四舍五入保留 4 位小数）。

### 5. 说明（notes）

- 必含口径声明（UDP-only、IAT 计算方式）。
- 条件性内容: 截断（`Limited to N packets.`）、被忽略包类型与数量（TCP/ICMP/非 IP）、未发现 UDP、文件不存在、解析错误、依赖缺失。
- 语义: notes 是画像可用性的唯一判断出口——调用方与 LLM 依赖它判断数据可信度。

### 6. 初始参数映射（profile → params，澄清 004-1 新增）

纯函数：输入画像 JSON，输出初始流量参数建议。

| 输出参数 | 映射规则 | 钳制 |
|---------|---------|------|
| `dst_port` | `top_dst_ports[0]`；画像无 UDP 时回落配置默认端口 | 1–65535 |
| `packet_size` | 直方图概率累计 ≥ 50% 的首个桶（中位数桶） | ≤ MAX_PACKET_SIZE(1024) |
| `flow_count` | `approx_flow_count` | 1–MAX_FLOW_COUNT(100) |
| `pps` | `1000 / iat_ms_stats.mean`（mean ≤ 0 或无 IAT 时回落配置默认） | 1–MAX_PPS(20000) |
| `duration_s` | 维持配置默认（画像不约束时长） | ≤ MAX_DURATION_S(20) |

**覆盖优先级**: CLI 显式参数 > 映射值 > `experiment.json` 默认值（人工覆盖入口在 CLI）。

## 关系

- 画像 **1─n** 流、**1─n** IAT 样本、**1─n** 包长桶（推导关系，画像是它们的聚合视图）。
- 初始参数映射 **1─1** 画像（每次映射纯函数、无状态）。
- 映射输出的参数在流量工具内部仍受 allowlist / 参数上限 / HITL 三重门禁约束（安全不变式）。

## 校验规则（跨实体）

- UDP-only 隔离：TCP/ICMP/非 IP 包不进入任何统计字段（FR-003/FR-012）。
- 截断诚实：读取包数达上限时必须在 notes 注明（FR-002）。
- 失败完整：任何异常路径返回字段完整结构 + 非空 notes，零崩溃（FR-010）。
- 概率口径：`packet_size_hist` 各桶之和 = 1（SC-003 验证隔离，SC-005 验证流数）。
