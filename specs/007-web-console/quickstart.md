# 快速开始 / 端到端验证：Web 控制台（实时实验监控与人工审批）

**特性目录**: `specs/007-web-console/` | **日期**: 2026-11-19

> 用途：实现完成后的人工验收基线。每一步列出操作、验证命令与预期结果。涉及真实流量发送的场景必须使用 allowlist 内目标；HITL 拒绝场景不产生流量。

## 前置条件

1. 依赖安装：`uv sync --extra dev`
2. LLM Key：复制 `.env_example` 为 `.env` 并填入 `DEEPSEEK_API_KEY`（实验执行需要）。
3. allowlist：确认 `src/config/allowlist.json` 含测试目标（如 `10.99.80.160`），`src/config/experiment.json` 中 `target_ip` 为合法目标。
4. 服务启动：

```bash
uv run uvicorn backend.server:app --host 0.0.0.0 --port 8000
```

5. 浏览器打开 `http://localhost:8000`。

## 场景 1：连接与内网声明（FR-001/002/003）

- 操作：打开页面。
- 预期：页面加载出暗色单页控制台；顶部状态栏显示「WS 已连接」徽章；页面可见「仅限可信内网使用」声明（G1）；服务启动日志含内网限定警告。

## 场景 2：默认值单一来源（FR-008、G4）

- 操作：清空表单重新加载页面，观察「目标 IP / 最大迭代次数 / 无改善停止轮数」初值。
- 预期：初值与 `src/config/experiment.json` 的 `target_ip / max_iters / no_improve_limit` 完全一致（修改配置后重启服务再刷新页面，初值随之变化）。

## 场景 3：PCAP 上传校验（FR-015/016、SC-010、G3）

- 操作：选择一个 `.pcap` 文件上传；再尝试 `.txt` 文件与超过 100MB 的文件。
- 预期：合法文件 → 消息面板显示「PCAP 上传成功」并回填路径（形如 `data/uploads/xxxxxxxx_name.pcap`）；非法扩展名 / 超大文件 → 服务端返回结构化错误（「不支持的文件类型」/「文件超过大小上限」），消息面板显示错误，且 `data/uploads/` 下无残留文件。

## 场景 4：启动、互斥与停止（FR-008/009/010、SC-009）

- 操作：点击「启动实验」→ 立即再点一次「启动实验」→ 点击「停止实验」。
- 预期：首次启动 → 状态「运行中」，面板收到启动确认（含线程标识）；第二次 → 收到「实验已在运行中，请先停止当前实验」且页面运行状态不被破坏（仍显示运行中，G5 修复后）；停止 → 实验结束消息推送，状态复位「就绪」。

## 场景 5：实时消息流（FR-004~007、SC-002/007）

- 操作：观察实验运行期间的消息面板。
- 预期：AI 消息（含工具调用徽章）、工具结果、状态消息按类型差异化渲染，面板自动滚动到最新一条；工具结果中的 RTT 观测字段完整可见（不被呈现层截断篡改）。

## 场景 6：HITL 审批闭环（FR-011~014、SC-003/004/005，核心门禁）

- 操作：实验触发流量工具时出现审批弹窗（提示 + 参数快照）：
  - 子场景 A：点击「批准」→ 实验继续，面板显示「HITL 审批通过」。
  - 子场景 B：点击「拒绝」→ 面板显示「HITL 审批拒绝」，该次工具调用被中止（工具结果标记拒绝），实验可继续但本次无流量。
  - 子场景 C：不点击任何按钮等待 60 秒 → 实验保持暂停，绝不自动放行。
- 预期：三个子场景行为如述；服务端日志可确认拒绝路径未产生任何发包动作。

## 场景 7：状态查询与断线容错（FR-017/020、SC-001/008）

- 操作：
  - `curl -s http://localhost:8000/api/experiment/status`（实验运行中与空闲各一次）。
  - 实验运行中强制关闭浏览器标签页，重新打开页面查询状态。
- 预期：状态接口返回 `{"running": true/false}` 与面板一致（99.9% 响应 <100ms）；断线后服务不崩溃、实验继续，重新打开页面后状态查询反映真实运行状态。

## 场景 8：单客户端会话隔离（007-2 决议、FR-002/013）

- 操作：浏览器 A 启动实验；浏览器 B（新 client_id）打开页面尝试审批 A 实验的 HITL 弹窗（B 不发起实验）。
- 预期：B 看不到 A 的实验消息流；B 的审批/停止消息被服务端以「非会话所有者」错误拒绝（G2 实现后）；A 在其会话内正常完成审批。
